# Thermal modeling

The [Slate Pocket v1R model](slate-pocket-v1r/model/model.yaml) defines a provisional geometry-specific thermal screen. The [test matrix](slate-pocket-v1r/test-matrix.yaml) and [correlation plan](slate-pocket-v1r/correlation-plan.md) describe the measurements needed to calibrate it. The readiness report is generated by `slate-pocket-v1r/generate_thermal_model_readiness_report.py`.

These files are planning inputs. They do not establish safe skin temperature, sustained power, or validated heat spreading without supplier data and prototype measurements.
