# Security policy

BuildSlate is an engineering model and local viewer. No device hardware or software release is represented by this repository.

Report a vulnerability privately through [GitHub's vulnerability reporting flow](https://github.com/superflyad/BuildSlate/security/advisories/new) when available. If that flow is unavailable, open an issue asking the maintainer for a private reporting channel without disclosing exploit details or sensitive files.

Include the affected revision, reproduction steps, impact, and any relevant configuration. Do not submit credentials, supplier confidential files, or personal data in a public issue. The maintainer will review the report, coordinate a fix, and disclose details after a remedy is available.

The current development branch is `main`. No supported release series or response-time guarantee has been established.
