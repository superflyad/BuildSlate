# Assembly viewer

The viewer is a local, read-only view of the Slate Pocket v1R editable concept CAD. It combines generated assembly geometry, part source references, evidence classes, keepouts, and the current program gate context. It does not edit repository inputs.

The public viewer is at [superflyad.github.io/BuildSlate](https://superflyad.github.io/BuildSlate/). The GitHub Pages deployment runs from `main` after repository validation and CAD export succeed.

## Run it

From the repository root, verify or regenerate the assembly assets before starting the web app:

```bash
python -m buildslate.assembly --check
python validation/validate_concept_cad.py
cd viewer
npm ci
npm run dev
```

Open the local address printed by Vite. If the assembly check reports stale output after an input change, run `python -m buildslate regenerate --stale` from the repository root. If the concept check reports stale output, run `python -m buildslate.cad` in the [CAD environment](../cad/slate-pocket-v1r/concept-cad/README.md). Review the generated diff before starting the viewer again.

## Explore the model

| Control | Use |
| --- | --- |
| Drag, scroll, select | Rotate, zoom, and inspect a part in the 3D viewport. |
| Concept CAD, Source envelopes | Switch between the 41-solid concept assembly and the original 26 source planning boxes. |
| 3D, Front, Rear, Side | Switch to a fixed camera orientation. |
| Fit model, Expand view | Restore the assembly camera or give the model the full browser area. Press Escape to leave the expanded view. |
| Search and Systems | Find components or filter a subsystem; **Show all** restores the list. |
| Explode assembly | Separate the solids to see the internal arrangement. |
| Section cut | Clip the model along X, Y, or Z; move the slider to position the cut in millimeters. The plane is a visual inspection aid, not an interference result. |
| Exterior | Hide or show the outer shell to expose internal parts. |
| Keepouts | Show reserved regions that should remain clear. |
| Deferred concepts | Show items that are not part of the current build. |
| Proof conflicts | Color concept solids with keepout or reservation conflicts. |
| Inspect | Focus or isolate a selected part and read its dimensions, evidence class, and source. |
| Program | Review every component library role, its source evidence status, concept solids, gates, and blockers. Click a represented part to inspect it. |
| Proof | Review solid integrity, STEP round trip, intersections, keepouts, and local thickness results. Select a finding to inspect its part. |

All displayed distances are in millimeters. The [assembly contract](../engineering/assembly/README.md) defines the coordinate frame, stable IDs, and source mapping.

## Generated asset contract

`public/assembly.json` and `.gltf` contain the 26 source planning envelopes. `public/concept.json` and `.gltf` contain the 41-solid editable concept. `public/proof.json` contains the per-part CAD proof and unresolved findings. The source pair is generated by `buildslate.assembly`; the concept and proof assets by `buildslate.cad` with Python 3.12 and `requirements-cad.txt`. The concept exporter also writes [STEP CAD](../cad/slate-pocket-v1r/concept-cad/README.md). Do not edit generated files by hand.

The viewer is a Vite static application. `npm run build` writes `dist/`, including the generated assets; `npm run preview` serves that build locally. `npm run build:pages` sets the `/BuildSlate/` base path for GitHub Pages. `npm run check:model` verifies that the glTF loads and contains the expected assembly meshes. `npm run format:check` checks the web source.

## Interpretation limits

Concept solids include rounded profiles, package recesses, a drilled board, speaker slots, camera lenses, a port opening, a coil reserve, and a gasket path. Their added placements and details are assumptions with source links. The [proofing method](../docs/engineering/cad_proofing.md) checks nominal geometry and exports, while keeping open conflicts visible. It does not prove physical fit, tolerance stack, electrical routing, thermal or RF performance, qualification, or manufacturing readiness. The Program tab reflects source registries and does not make a release decision. Replacing a concept solid requires reviewed supplier or design geometry with revision, units, coordinate transform, evidence class, and acceptance review.
