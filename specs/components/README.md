# Component specifications

No supplier-qualified component specification is committed here. The current Slate Pocket v1R component roles and selection requirements live in [EVT0 BOM strategy](../../validation/evt0/bom-strategy.yaml); public candidates remain references in `research/evidence/`.

Add a selected component specification only after the controlled supplier response and configuration review establishes its part number, revision, package, electrical limits, lifecycle, and source drawing. Keep proprietary supplier material in an approved storage location and record only permitted references here.
