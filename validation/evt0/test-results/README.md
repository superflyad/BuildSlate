# EVT0 Test Results

No EVT0 measurement results exist.

Real campaigns create an immutable directory per `campaign_id/unit_id/run_id` containing:

- a schema-valid run manifest and result summary;
- raw, unfiltered instrument/platform/workload logs;
- calibration references, setup photographs, fixture/configuration records, and operator event log;
- analysis scripts/notebooks pinned by hash and their generated outputs;
- deviations, invalidation/disposition, review comments, and signatures.

Templates, generated readiness reports, manually typed summaries without raw data, and files lacking unit/configuration/workload/calibration identity are not test evidence. Failed and invalid runs remain in the campaign record.
