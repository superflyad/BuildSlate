# Support

Use [GitHub Issues](https://github.com/superflyad/BuildSlate/issues) for reproducible defects, documentation errors, and missing engineering evidence. Search existing issues first. Include the affected device profile, source path, command, and observed output where relevant.

For a question about the model, start with the [documentation index](docs/README.md), [architecture](ARCHITECTURE.md), and [program dashboard](reports/program/dashboard.md). The dashboard states the current evidence and release limits.

Do not post supplier confidential material, credentials, personal data, or an exploitable security issue in a public issue. Follow the [security policy](SECURITY.md) for sensitive reports. Supplier evidence belongs in the controlled intake workflow described in the [operator guide](docs/engineering/operator_workflows.md).
