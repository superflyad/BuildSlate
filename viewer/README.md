# Assembly viewer

The viewer is a local, read-only view of the Slate Pocket v1R planning model. It combines generated assembly geometry, part source references, evidence classes, keepouts, and the current program gate context. It does not edit repository inputs.

## Run it

From the repository root, verify or regenerate the assembly assets before starting the web app:

```bash
python -m buildslate.assembly --check
cd viewer
npm ci
npm run dev
```

Open the local address printed by Vite. If the assembly check reports stale output after an input change, run `python -m buildslate regenerate --stale` from the repository root, review the generated diff, and start the viewer again.

## Explore the model

| Control | Use |
| --- | --- |
| Drag, scroll, select | Rotate, zoom, and inspect a part in the 3D viewport. |
| 3D, Front, Rear, Side | Switch to a fixed camera orientation. |
| Fit model, Expand view | Restore the assembly camera or give the model the full browser area. Press Escape to leave the expanded view. |
| Search and Systems | Find components or filter a subsystem; **Show all** restores the list. |
| Explode assembly | Separate the planning envelopes to see the internal arrangement. |
| Section cut | Clip the model along X, Y, or Z; move the slider to position the cut in millimeters. The plane is a visual inspection aid, not an interference result. |
| Exterior | Hide or show the outer shell to expose internal parts. |
| Keepouts | Show reserved regions that should remain clear. |
| Deferred concepts | Show items that are not part of the current build. |
| Inspect | Focus or isolate a selected part and read its dimensions, evidence class, and source. |
| Program | Review every component library role, its box, aggregate, deferred, or unplaced representation, and the generated gates and blockers. Click a represented part to inspect it. |

All displayed distances are in millimeters. The [assembly contract](../engineering/assembly/README.md) defines the coordinate frame, stable IDs, and source mapping.

## Generated asset contract

`public/assembly.json` carries names, groups, dimensions, source paths, evidence classes, and gate context. `public/assembly.gltf` carries the matching geometry. Both are generated by `buildslate.assembly` from the [assembly manifest](../engineering/assembly/assembly.yaml), mechanical envelopes, keepouts, zone stacks, PCB floorplan, and program dashboard. Do not edit either file by hand.

The viewer is a Vite static application. `npm run build` writes `dist/`, including the generated assets; `npm run preview` serves that build locally. `npm run check:model` verifies that the glTF loads and contains the expected assembly meshes. `npm run format:check` checks the web source.

## Interpretation limits

Every current solid is a planning box, including the shell and internal parts. The display does not prove physical fit, tolerance stack, electrical routing, thermal or RF performance, qualification, or manufacturing readiness. The Program tab reflects source registries and does not make a release decision. Replacing a box requires reviewed supplier or design geometry with revision, units, coordinate transform, evidence class, and acceptance review.
