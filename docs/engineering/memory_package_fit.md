# 128 GB memory package screen

The current board has four 14 × 10 mm planning sites, each labeled 32 GB. They express the approved 128 GB capacity target, not selected DRAM geometry. [Samsung lists a 32 GB LPDDR5X capacity](https://semiconductor.samsung.com/dram/lpddr/lpddr5x/), and [Micron announced an intended 8–32 GB range](https://investors.micron.com/news/press-release/2025/Micron-Ships-Worlds-First-1-1-Gamma-Based-LPDDR5X-Enabling-Rich-Mobile-AI-Experiences-06-03-2025/default.aspx), but the reviewed public sources do not provide an exact 32 GB manufacturer part number, package drawing, and X2 qualification for those sites.

For a concrete comparison, Micron lists [`MT62F2G64D8EK-023 WT:C`](https://www.micron.com/products/memory/lpddr-components/lpddr5x/part-catalog/part-detail/mt62f2g64d8ek-023-wt-c) as a 128 **gigabit** (16 **gigabyte**) LPDDR5X part in a 14 × 14 × 1.1 mm, 441-ball package. Eight such parts would total 128 GB. The current board reserves four sites of 14 × 10 mm and the assembly uses 1.0 mm nominal package height, so this exact package does not fit even one planning site. Eight package outlines alone would occupy 1,568 mm², compared with 560 mm² reserved by the four rectangles. This is an area and outline screen, not a proposed eight-package layout.

## Eight-package outline study

The separate [placement study](../../engineering/pcb/slate-pocket-v1r-floorplan/memory-8x16-study.yaml) tests four 14 × 14 mm packages on the component side and four at matching locations on the reverse side. Against the current non-memory planning blocks, the component boundary, and an **assumed** 1.0 mm planar gap rule, the closest screened gap is 1.5 mm. The reverse side has no other components in the present floorplan. This establishes only that the eight package *boxes* can be drawn inside the board planform in that arrangement.

The floorplan, mechanical board envelope, and compute-zone stack now use the same provisional 0.8 mm PCB thickness. The board top stays at z = 4.0 mm; reverse-side package bottoms move to z = 2.1 mm. This resolves an internal drawing mismatch, not fabrication feasibility. The study still does not test land patterns, bottom-side assembly, vias and escape, decoupling, shielding, heat flow, actual memory-controller topology, or a booted device. The eight boxes replace the four planning solids only in the separate [45-solid STEP alternative](../../cad/slate-pocket-v1r/concept-cad/memory-8x16.step) and its matching public 3D view. The baseline remains unchanged. Both exports have independent CAD proof reports.

Run `python -m buildslate.memory_package_fit` to recompute the comparison and outline study from the profile, public part record, board floorplan, and assembly. The [Hardware view](https://superflyad.github.io/BuildSlate/?tab=hardware) reports both. The check rejects confusion between gigabits and gigabytes, false clearances, and promotion of planning sites to verified geometry.

The 128 GB floor remains unchanged. Closing the gap requires either a qualified exact 32 GB package and reviewed four-package topology or a new eight-package electrical and mechanical design. Both routes need Qualcomm's supported X2 channel and rank map, memory rails, signal rules, package drawings, board routing, boot firmware, power and thermal tests, and the measured [resident-memory exercise](compute_platform_decision.md#resident-memory-exercise) on a serialized Slate unit. A public controller maximum is insufficient.
